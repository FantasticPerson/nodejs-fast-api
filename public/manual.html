01

快速开始

  1. 确认运行环境。Node.js 需要 22.14 或更高版本；需要连接 MySQL / Oracle 时再安装对应驱动。
  2. 安装并启动。在项目目录执行 npm install，然后执行 npm start。
  3. 打开管理台。浏览器访问 http://127.0.0.1:3000/magic。
  4. 添加数据源。进入「数据源」，新增 MySQL 或 Oracle 连接并测试连接。
  5. 创建第一个接口。可以浏览表结构后一键生成 CRUD，也可以点击「新建接口」手写 SQL 或 JavaScript 脚本。
服务检查

启动后可访问 /magic/api/health 检查服务状态。数据库驱动未安装时管理台仍可启动，但对应数据源无法连接。

03

数据源管理

添加 MySQL

进入「数据源」→「添加数据源」，填写主机、端口、数据库名、用户名和密码，然后点击「测试连接」。MySQL 默认端口为 3306。

添加 Oracle

Oracle 默认端口为 1521。连接方式必须明确选择：

  • 服务名：连接串形如 HOST:PORT/SERVICE_NAME。
  • SID：连接串形如 HOST:PORT:SID。

Oracle 11g 需要 Oracle Client 库并启用 Thick 模式；Oracle 12.1 及以上可以使用默认 Thin 模式。详细部署步骤见项目根目录的 docs/offline-deployment.md。

只读数据源

开启「只读数据源」后，只允许查询语句；写接口仍然保留，但运行时会返回 HTTP 403 和错误码 DATASOURCE_READ_ONLY。自动 CRUD 对只读数据源只生成查询接口。

密码安全

数据源密码只加密落盘，不会出现在接口响应、调用日志或错误消息中。不要把管理台直接暴露到公网。

04

一键生成 CRUD

  1. 在数据源卡片点击「浏览表」。
  2. 选择目标表，确认字段、主键和字段是否可空。
  3. 点击「生成 CRUD」，设置路径前缀和需要生成的方法。
  4. 查看预览后确认创建，接口会立即出现在「接口」页。

生成接口默认使用表名作为分组名，可在接口编辑页改成其他分组。只读数据源不会生成新增、更新和删除接口。

主键限制

联合主键暂不支持自动 CRUD，请改用自定义 SQL 接口。没有单列主键的表通常只能生成列表和新增。

05

接口与分组

「接口」页左侧是分组导航，右侧只显示当前分组中的接口。

  • 默认分组：始终排在第一，分组字段留空的接口归入这里。
  • 自定义分组：接口填写分组后自动出现在导航中，按名称排序并显示接口数量。
  • 切换分组：点击任意分组，右侧列表和搜索范围都会切换到该组。

编辑接口分组

编辑接口时，分组输入框支持三种方式：

  • 完全留空，保存后归入「默认分组」。
  • 从下拉建议中选择已经存在的分组。
  • 直接输入新名称，保存后创建新的分组。

保存接口后会回到它所属的分组，方便继续编辑同组接口。

06

SQL 接口

点击「新建接口」，实现方式选择「SQL 接口」，然后填写接口名称、请求方法、接口路径、数据源和 SQL 模板。

安全参数绑定

SELECT id, name
FROM users
WHERE id = #{id}

#{name} 会转换成数据库绑定参数，默认推荐使用。${name} 会原样拼接，只有在接口选项里显式开启「允许原样 SQL」后才可使用。

动态 SQL 标签

<if test="name != null and name != ''">
  AND name LIKE CONCAT('%', #{name}, '%')
</if>

<foreach collection="ids" item="id" separator=",">
  #{id}
</foreach>

支持 <if>、<choose>、<foreach>、<set> 和 <where> 等动态标签。

分页与响应

开启自动分页后，接口会接收 page、pageSize，并自动追加总数查询。响应模式可以选择统一包装 { code, message, data }，或直接返回数据。

07

JavaScript 脚本接口

实现方式切换到「JavaScript 业务脚本」后，脚本在独立 Worker 中运行，不提供 require、process 和文件系统。

常用上下文

API用途
ctx.params当前接口参数
ctx.request请求信息，如 method、path、query、body、headers
ctx.endpoint当前接口元信息
ctx.libs已启用的共享脚本，通过 ctx.libs.名称.函数() 调用
ctx.plugins服务端插件提供的 action
ctx.logger写入脚本运行日志
dbquery、queryOne、execute、transaction
httpfetch，需接口开启外部 HTTP 且命中服务端白名单

返回数据

const row = await db.queryOne(
  'SELECT id, name FROM users WHERE id = #{id}',
  { id: ctx.params.id }
);

ctx.logger.info('loaded user', row.id);
return row;

补全与速查卡

输入 ctx.、db.、ctx.libs. 等前缀会自动出现补全；也可以按 Ctrl + Space 手动打开。macOS 还支持 Option + /。

  • ↑ / ↓ 切换候选，Enter 或 Tab 插入，Esc 关闭。
  • 字符串和注释内部不会触发补全。
  • 共享脚本方法通过静态解析顶层 return { ... } 获取；动态对象或展开运算无法识别时，会展示完整源码供手动查看。
外部 HTTP

接口开启「允许外部 HTTP」只是第一步，目标域名还必须命中服务端的 SCRIPT_HTTP_ALLOWLIST 白名单。

08

共享脚本

「共享脚本」页用于维护可复用的公共函数。只有启用的共享脚本会出现在脚本接口的 ctx.libs 补全和速查卡中。

return {
  normalize(value) {
    return String(value || '').trim().toLowerCase();
  },
  async findUser(id) {
    return await ctx.db.queryOne('SELECT id, name FROM users WHERE id = #{id}', { id });
  }
};

在业务脚本中这样调用：

const name = ctx.libs.helpers.normalize(ctx.params.name);

共享脚本支持启停、描述、版本快照和恢复。修改共享脚本后，所有引用它的接口在下一次调用时使用新版本。

09

调试与调用日志

  1. 在编辑页右侧的「测试参数 JSON」填写请求参数。
  2. SQL 接口可以点击「预览 SQL」检查绑定结果，再点击「运行接口」执行真实查询。
  3. 脚本接口点击「运行脚本」，页面会显示返回结果和脚本日志。
  4. 快捷键 ⌘ / Ctrl + Enter 可以运行当前接口。

真实调用会记录到「调用日志」，包括方法、路径、状态码、耗时和错误信息。日志只保留最近 200 条。

超时

全局查询超时由 QUERY_TIMEOUT_MS 控制，接口级 0 表示使用全局值。超时返回 HTTP 504 和错误码 DB_QUERY_TIMEOUT。脚本接口默认由 SCRIPT_TIMEOUT_MS 控制，也可在接口选项中覆盖。

10

接口文档与调用

已启用的接口会自动出现在「接口文档」页，也可以直接读取 OpenAPI JSON：

http://127.0.0.1:3000/magic/api/openapi.json

OpenAPI 原始地址通常是 /magic/api/openapi.json，生成接口位于 /openapi/*。管理台页面中的 cURL 示例可以直接复制使用。

访问令牌

  • ADMIN_TOKEN 保护管理接口和 OpenAPI 文档。
  • OPENAPI_TOKEN 保护实际运行的接口，请求需带 x-api-token 或 Bearer token。
  • 未配置 ADMIN_TOKEN 时，管理接口只允许本机回环地址访问。
文档同步

接口保存或启停后，OpenAPI 文档会随当前接口状态更新，不需要单独发布步骤。

11

版本历史

接口和共享脚本每次保存都会生成一个版本快照。编辑已有接口时，点击「历史版本」可以查看旧版本并恢复。

  • 恢复版本会生成一条新的当前状态记录，不会删除已有历史。
  • 适合在改错 SQL、脚本或分组配置后快速回退。
  • 版本保存只针对接口定义和脚本内容，不包含调用日志。
12

常见问题

管理页打不开或提示需要访问令牌

检查服务是否启动、访问地址是否为 /magic。如果配置了 ADMIN_TOKEN，点击右上角「访问令牌」填入相同令牌。

数据源连接失败

先确认对应驱动已安装：MySQL 使用 mysql2，Oracle 使用 oracledb。再检查主机、端口、账号、密码和连接方式。Oracle 11g 还需要 Client 库和 Thick 模式。

接口返回 403 或 DATASOURCE_READ_ONLY

当前数据源开启了只读模式，写语句会在进入数据库前被拒绝。需要写入时关闭只读，或改用具有写权限的非只读数据源。

接口返回 504 或 DB_QUERY_TIMEOUT

查询执行超过全局或接口级超时。缩小查询范围、优化 SQL，或在接口选项中调整超时值。

脚本里看不到共享脚本方法

确认共享脚本已启用；补全只解析顶层 return { ... } 中的静态方法。动态生成的对象无法被静态识别，请展开「查看共享脚本代码」手动确认。

分组里没有接口

接口的分组字段留空会进入「默认分组」；填写名称后才进入对应自定义分组。可以在编辑页重新选择或输入分组。

读取 OpenAPI 返回 401 或 403

检查 ADMIN_TOKEN 配置，并在请求中携带有效管理令牌。
